# 数据重置指南

把网关数据恢复到想要的初始状态。工具：`reset.ps1`

---

## 先看现状（不做任何修改）

```powershell
cd <项目目录>
.\reset.ps1
```

或显式指定：

```powershell
.\reset.ps1 -Level status
```

输出示例：

```
   AI 计费网关 · 当前数据状态
  ══════════════════════════════════════════════════════
   数据库 : ai_billing @ 127.0.0.1:3306
   连接账号: root

   API Key 数量    : 3
   定价规则          : 2
   用量明细          : 148
   管理账号          : 1
   审计日志          : 42

   累计 Token: 1250000    累计费用: 187.5    累计请求: 3200
```

## 四个重置级别

| 级别 | 会删掉 | 保留 | 适用场景 |
|---|---|---|---|
| `账单` | 用量明细、累计用量、审计日志 | Key、定价、账号 | 账目重算，客户端无需改动 |
| `key` | Key、定价、账单 | 管理员账号 | 回到刚部署完的状态 |
| `全部` | 上述 + 管理员账号 | 仅 `appsettings.json` 配置 | 彻底重来 |
| `库` | `DROP DATABASE` 整库 | 无（重启自动重建） | 等价全新部署 |

### 级别一：只清账单

```powershell
.\reset.ps1 -Level 账单
```

- 清空 `usage_records`
- 所有 Key 的 `used_*` 累计字段归零
- **Key 和定价不动**，客户端无需任何改动

适合「历史账单作废、从今天重新计」。

### 级别二：清 Key + 定价

```powershell
.\reset.ps1 -Level key
```

> ⚠️ **所有 API Key 会被删除，客户端立即失效，且明文无法找回** —— 需要重新创建并分发给各使用者。

### 级别三：全部重置

```powershell
.\reset.ps1 -Level 全部
```

管理员账号也会被清掉，登录回退到 `appsettings.json` 里的初始账号（默认 `admin` / `admin123`）。

### 级别四：直接删库

```powershell
.\reset.ps1 -Level 库
```

删掉整个 `ai_billing` 库。**重启网关时会自动重建所有表**（含增量迁移）。

## 安全机制

### 1. 自动备份

默认每次重置前都会 `mysqldump` 到 `backups\ai_billing_<时间戳>.sql`：

```
   [1/2] 备份
   正在备份到 ...\backups\ai_billing_20260912_163045.sql ...
   ✓ 备份完成：...\backups\ai_billing_20260912_163045.sql  (17.7 KB)
```

**备份失败会自动中止重置**，不会在无备份的情况下删数据。

跳过备份（不推荐）：

```powershell
.\reset.ps1 -Level 账单 -NoBackup
```

### 2. 二次确认

必须输入**大写 `YES`**，其他任何输入都取消：

```
  此操作不可撤销。
  请输入大写 YES 以确认执行（其他任何输入都会取消）：
```

非交互式会话（脚本/CI）下 `Read-Host` 不可用，脚本会**自动取消**而不是默默执行。

### 3. 预演模式

先看会执行什么，不实际改动：

```powershell
.\reset.ps1 -Level key -WhatIf
```

输出会明确列出「将删除」和「保留」的内容。

### 4. 无人值守执行

```powershell
.\reset.ps1 -Level 账单 -Force      # 跳过确认，仍需备份
```

## 从备份恢复

```powershell
$mysql = "<MySQL安装目录>\bin\mysql.exe"
$env:MYSQL_PWD = "root"

# 恢复（若库已存在，先删掉避免冲突）
& $mysql -h 127.0.0.1 -u root -e "DROP DATABASE IF EXISTS ai_billing;"
Get-Content ".\backups\ai_billing_20260912_163045.sql" -Raw | & $mysql -h 127.0.0.1 -u root
```

---

## 手工做同样的事（不用脚本）

```powershell
$mysql = "<MySQL安装目录>\bin\mysql.exe"
$env:MYSQL_PWD = "root"

# 只清账单
& $mysql -h 127.0.0.1 -u root -e "USE ai_billing; TRUNCATE TABLE usage_records; UPDATE api_keys SET used_prompt_tokens=0, used_completion_tokens=0, used_requests=0, used_cost=0;"

# 清 Key + 定价 + 账单
& $mysql -h 127.0.0.1 -u root -e "USE ai_billing; TRUNCATE TABLE usage_records; TRUNCATE TABLE api_keys; TRUNCATE TABLE model_prices;"

# 完全重置
& $mysql -h 127.0.0.1 -u root -e "USE ai_billing; TRUNCATE TABLE usage_records; TRUNCATE TABLE api_keys; TRUNCATE TABLE model_prices; TRUNCATE TABLE admin_users; TRUNCATE TABLE audit_logs;"

# 删库
& $mysql -h 127.0.0.1 -u root -e "DROP DATABASE IF EXISTS ai_billing;"
```

## 重置后要做什么

| 级别 | 后续步骤 |
|---|---|
| `账单` | 无需操作，Key 和定价都在 |
| `key` | 重新设定价 → 重新建 Key 并分发 |
| `全部` | 同上，且用 `appsettings.json` 的初始账号登录 |
| `库` | 同上，且需**重启网关**以重建表 |

```powershell
# 重新配置定价
dotnet src\AiBilling.Cli\bin\Release\net8.0\aibilling.dll prices set --model "*" --in 1 --out 2

# 创建 Key
dotnet src\AiBilling.Cli\bin\Release\net8.0\aibilling.dll keys create --name "客户A" --tokens 1000000 --cost 100

# 用 "库" 级别后需重启网关
start-gateway.cmd
```

## 常见问题

**Q：重置时网关需要停止吗？**
不必须，但建议停。网关运行时会缓存 Key（默认 15 秒），重置后短时间内可能有缓存不一致。脚本检测到 8080 被占用会给出提示。

**Q：`TRUNCATE` 和 `DELETE` 有什么区别？**
`TRUNCATE` 更快、重置自增 ID，但不可回滚。本脚本用 `TRUNCATE` 是刻意的 —— 重置就该完全干净，Key 的 ID 从 1 重新开始。

**Q：能只重置某一个 Key 吗？**
用 CLI 更合适：
```powershell
aibilling.dll keys reset 3        # 清零某个 Key 的累计用量
aibilling.dll keys delete 3       # 删除某个 Key
```

**Q：备份文件会一直堆积吗？**
会，脚本不做自动轮转。建议定期清理 `backups\` 目录，或把整个目录排除在版本控制外。

**Q：`-Force` 和 `-WhatIf` 能一起用吗？**
能，但 `-WhatIf` 优先 —— 只预演，不会真的执行。
